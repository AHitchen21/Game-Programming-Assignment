# Game Programming Assignment

A C++ based project developed for a university module. The project focuses on game design, coding and understanding game logic. 

## Technologies Used

* C++
* SDL

## My contributions

* Designing and implementing gameplay mechanics
* Adding sound and sprites
* Creating C++ classes to extend functionality

## Running the Project

1) Download and extract files.
2) Open the project file "Game Programming Assignment.sln" in Visual Studio.
3) Run the debugger.
