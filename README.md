# Game Programming Assignment

A 2D shooter game developed from scratch in C++ using the SDL library. The project focused on building core engine systems and implementing a playable game demo, with only a minimal code framework provided. This involved developing gameplay functionality, rendering systems, input handling, and game logic while applying object-oriented programming principles.

## Technologies Used

* C++
* SDL

## My contributions

* Designed and implemented gameplay mechanics.
* Developed player movement and interaction systems.
* Integrated sprites, animations, and audio assets.
* Created and extended C++ classes to support game functionality.
* Implemented game logic and state management systems.
* Debugged and tested features throughout development.

## Running the Project

1) Download and extract files.
2) Open the project file "Game Programming Assignment.sln" in Visual Studio.
3) Run the debugger.
